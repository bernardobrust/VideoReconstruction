# Video Inspector
### Goals
This part of the project serves as a tool for visualizing compression data generated by the AV1 video format, with the following end goals (check [`sources.md`](../../sources.md)):
- Study the use of generated motion vectors in computer vision (dense SfM, pos32 cloud generation, finding the camera position, etc.) ([sources](../../sources.md), `research` > `computer vision` > `2`)
- Use of luma channels for understanding depth
- Similarities between computer vision methods involving 3 images and video (solving the trifocal problem ([sources](../../sources.md), `research` > `computer vision` > `1`) using 3 frames)
- Image feature detection ([sources](../../sources.md), `research` > `computer vision` > `2`)
- Use of macroblocks and intra-prediction for estimation of low-detail objects

### Usage
After building (see the [README](../README.md) one level up) or downloading the binary (not available yet), you can run the inspector it with the following command:
```bash
inspector -inspect (video_file)
```

Then use the following commands:
- SPACE: Pauses/unpauses the video
- DOWN ARROW: Decrease playback speed
- UP ARROW: Increase playback speed
- F: Toggle full screen
- T: Toggle data overlay
- CTRL-LMB: Zoom in
- CTRL-RMB: Zoom out
- RMB: Pan the camera

You can also export the data to a file in this [format](../docs/export_format.md):
```bash
inspector -export (this_video_data) (to_this_file.dat)
```
