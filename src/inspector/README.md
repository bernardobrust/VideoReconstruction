# Video Inspector
### Goals
This part of the project serves as a tool for visualizing compression data generated by the AV1 video format, with the following end goals (check [`sources.md`](../../sources.md)):
- Study the use of generated motion vectors in computer vision (dense SfM, point cloud generation, finding the camera position, etc.) ([sources](../../sources.md), `research` > `computer vision` > `2`)
- Use of luma channels for understanding depth
- Similarities between computer vision methods involving 3 images and video (solving the trifocal problem ([sources](../../sources.md), `research` > `computer vision` > `1`) using 3 frames)
- Image feature detection ([sources](../../sources.md), `research` > `computer vision` > `2`)
- Use of macroblocks and intra-prediction for estimation of low-detail objects
