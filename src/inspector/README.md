# Video Inspector
### Goals
This part of the project serves as a tool for visualizing compression data generated by the AV1 video format, with the following end goals (check [`sources.md`](../../sources.md):
- Study the use of generated motion vectors in computer vision (dense SfM, point cloud generation, finding the camera position, etc.)
- Use of luma chanels for understanding depth
- Similarities between computer vision methods involving 3 images and video
- Image feature detection
- Use of macroblocks and intra-prediction for estimation of low-detail objects
